Check a copy

Drop a zip, an app folder or any file from one, and this page tells you whether it is exactly what we released.

Your browser works out each file's fingerprint on your own computer and compares it with the published list. Nothing is uploaded.

Drop it here

A downloaded zip, a whole app folder, or single files

Prefer to check it yourself?

In PowerShell: Get-FileHash "the file". In Command Prompt: certutil -hashfile "the file" SHA256. Then compare the result with the list on the app's page.
