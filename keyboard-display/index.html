Keyboard Display

A big on-screen keyboard that lights up as you type.

Download for Windows (1.1.1, 0.02 MB zip) Try it in your browser

Version 1.1.1 · Teacher guide

Shows a large keyboard on the board. Each key you press lights up and stays lit until the next press, so students can find the same key on their own keyboards.

Shortcuts are spelt out above the keyboard: press Shift + S and it reads Shift + S, then the letter it makes.

  • Every key and shortcut lights up as you press it
  • Eight themes, and any colour you like for keys, letters and glow
  • Record a word or sentence and replay it slowly for the class
  • Full screen for the class; the buttons fade away

Getting started

  1. Download the zip, then right-click it and choose Extract All. It won't run from inside the zip.
  2. Copy the Keyboard Display folder wherever you like: a flash drive, a network drive or your Documents.
  3. Double-click Start Keyboard Display.cmd. If Windows says the file is blocked, open Start in browser.html instead: it's the same app in a browser tab.

Made for Windows with Microsoft Edge or Google Chrome. Nothing is installed, no admin rights are needed, and it works without internet. Settings are kept in your browser on that computer only.

Is my copy the real one?

Every released file has a fingerprint (its SHA-256 checksum). Change one letter of a file and its fingerprint changes completely. Only copies that match the fingerprints below are ours; anything else isn't the file we released, so please download a fresh copy from here.

Open code

Keyboard Display is plain HTML and JavaScript: open the System folder and every line is there to read. Nothing is compiled or hidden, and it makes no calls to the internet. You're welcome to have your IT team look it over.
