Help

Press any key or combination. The keys light up and stay lit until the next key is pressed, so students can copy them.

Sequence: click ● Record, type, then click ■ Stop recording. Or type a phrase into the box and click Use text. ▶ Play replays it using the hold and gap times. The phrase shows greyed out and is inked in as each key plays. Pressing a key during playback pauses it.

Windows always keeps some shortcuts for itself (Ctrl+Alt+Del, Win+…, Alt+Tab). In Full screen, Chrome/Edge also pass shortcuts such as Ctrl+W and Ctrl+T to the page. To leave full screen, hold Esc.

Settings are remembered by this browser. Use Export to copy themes and sequences to a USB drive or another computer.
