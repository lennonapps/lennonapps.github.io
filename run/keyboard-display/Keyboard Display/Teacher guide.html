Keyboard Display: teacher guide

Version 1.1.1. Shows a large on-screen keyboard. Each key you press lights up and stays lit until the next press, so students can find the same keys on their own keyboards.

What's in the folder

Keyboard Display\
  Start Keyboard Display.cmd   double-click to start
  Start in browser.html        use this if the .cmd file is blocked
  Teacher guide.html           this guide
  System\                      the app itself (no need to open)

Copy the whole Keyboard Display folder to a flash drive, a network drive or your Documents. It runs on any Windows computer with Microsoft Edge or Google Chrome. Nothing is installed, no admin rights are needed, and it works without internet.

Getting started

  1. If you received a .zip file, right-click it and choose Extract All first. It will not work from inside the zip.
  2. Double-click Start Keyboard Display. The app opens in its own window. (If Windows says the file is blocked, use Start in browser.html instead; it is the same app in a browser tab.)
  3. Press any key or combination, e.g. Shift + S. The caption above the keyboard reads Shift + S → “S”.
  4. Click Full screen for the classroom display. Hold Esc to leave full screen.

The buttons fade after a few seconds without the mouse. Move the mouse to bring them back.

Themes and colours

Click Settings. Pick one of the eight themes, then click any colour (background, keys, letters, pressed key, glow, text…) to change it with the colour wheel. Glow size, glow strength and key rounding have sliders. Type a name under Save this theme to keep your own.

Demonstrating a word or sentence

  1. Click Sequence.
  2. Either click Record, type, then click Stop recording, or type text into the box and click Use text.
  3. Click Play. Each key lights for the Hold time, goes dark for the Gap, and the next key follows. The text shows in grey above the keyboard and turns black as each letter is typed. Tick Loop to repeat it.
  4. Click Save to keep a sequence for next lesson.

Moving to another computer

Themes and sequences are remembered by the browser on each computer. To take them with you, open Settings and click Export themes & sequences. Save the file on your flash drive, then use Import on the other computer.

Keys that can't be shown

Windows keeps a few shortcuts for itself (Ctrl+Alt+Del, Alt+Tab, Windows+…). In full screen most browser shortcuts, such as Ctrl+W, are shown instead of acted on.
